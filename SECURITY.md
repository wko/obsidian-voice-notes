# Security Policy

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue for a suspected vulnerability.

Include the affected version, platform, reproduction steps, impact, and any suggested mitigation. Please avoid including real API keys, recordings, transcripts, or vault contents in the report.

## Scope

Voice Append handles microphone input, an OpenAI API key, local recordings, transcripts, optional note context, and writes to the active Obsidian vault. Reports involving unintended disclosure, unauthorized network requests, unsafe note modification, or loss of recoverable recordings are especially helpful.
